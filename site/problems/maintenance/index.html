🚧 Problem type: maintenance

This page is the type URI of the application/problem+json answer (RFC 9457) that Maintenance Manager sends while an app is blocked for planned maintenance. If your API client got it, the service is not broken: it is down on purpose, for a while.

What it looks like

HTTP/1.1 503 Service Unavailable
Content-Type: application/problem+json
Cache-Control: no-store
Retry-After: Fri, 30 Oct 2026 22:30:00 GMT

{"type":"https://maintenance-manager.oss.life.li/problems/maintenance",
 "title":"Back soon","status":503,"detail":"Planned database upgrade.",
 "window":"db-upgrade","until":"2026-10-30T22:30:00Z"}
status
Always 503.
title, detail
Texts from the maintenance page, in the language the request asked for.
window
The name of the maintenance window.
until
When the current phase is planned to end (RFC 3339, UTC), or null when that is not known.

What a client should do

  • Do not treat it as an error to alert on. Treat it as "come back later".
  • When there is a Retry-After header, try again after that time: it is when the whole block is planned to end. Without one, back off and retry.
  • Show title and detail to people, if you show anything.

GET and HEAD requests that accept text/html get the maintenance page instead. More in the README.
